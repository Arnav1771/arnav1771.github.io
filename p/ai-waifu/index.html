The Forge

Every companion is a JSON file you can read

Characters persist as portable JSON — shareable, versionable, remixable. Override any built-in response line in their voice; placeholders substitute at runtime.

config / characters / reia.json
{
  "name": "Reia",
  "archetype": "tsundere",
  "wake_word": "hey reia",
  "palette": { "primary": "#A855F7", … },
  "lines": {
    "open_app": "Opening {target}. Try not to waste too much time."
  }
}
Quick start

Running in three commands

git clone https://github.com/Arnav1771/Ai-waifu.git
cd Ai-waifu
pip install -r requirements.txt
python main.py
1 · Add a free Gemini key. First run opens Settings — paste a key from aistudio.google.com.
2 · Pick a companion. Activate one of the legendary six from the gallery.
3 · Or forge your own. Name, soul, palette, voice, wake word — save and activate.
