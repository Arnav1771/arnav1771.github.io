Quick Start

Grimoire turns a plain-English description into a working, documented codebase pushed to a private GitHub repo on your account. Pick whichever surface you already live in:

# Browser — zero install (keys stay in your browser) open conjure.html on this site → paste GitHub token + Gemini/Claude key → CONJURE # Discord — in any server the bot has joined /build a recipe app with search /model # switch provider / model # Self-host the engine (CLI, bot, everything) git clone https://github.com/Arnav1771/turmux_builder pip install -r requirements.txt python main.py # .env holds your keys
Try it outLIVE → CONJURE APP

The Two-Pass Engine

Pass 1 — Plan. The model returns structured JSON: repo name, tech stack, and a full file tree with a purpose for each file.

Pass 2 — Generate. Each file is written in its own call with the whole plan as context, so imports and structure line up. The result is committed file-by-file to a new private repo through the GitHub API — no local git required.

Bring Your Own Keys

There is no backend and no account. In the browser, keys persist only in localStorage (opt-out checkbox) and are sent directly to your provider and GitHub over HTTPS. Self-hosting reads keys from .env.

IMP_DOCS

Every conjured repo ships a standardized IMP_DOCS/ folder — HANDOFF, PROMPT_TRAIL and friends — plus HOW_TO_RUN.md and a CI validate-build.yml, so a teammate can pick the project up cold.
