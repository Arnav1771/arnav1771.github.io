The ritual

Four movements. One repo.

Speak

“A Flask todo app with SQLite and a dark-mode UI.” Plain English is the entire spec.

Plan

Pass one returns the architecture as structured JSON — repo name, stack, and every file with its purpose.

Conjure

Pass two writes each file with the whole plan in context, so imports and structure truly line up.

Bind

A private repo appears on your GitHub — committed via API with CI and IMP_DOCS/ from the first commit.

⚙️

Infrastructure Included

Every conjured repo ships runnable structure — Dockerfile, CI build-check, HOW_TO_RUN.md and a standardized IMP_DOCS/ folder.

🔮

Multi-Provider Support

Access best-in-class models — switch between GitHub Models, Gemini, Groq and Claude per build. Only Claude needs its own key.

🌀

One Engine, Every Surface

Build from Claude, the MCP server, the CLI or Termux, Discord, or this site — the same core answers everywhere.
